How it works

System audio → shaders, every frame

Kaleidosync captures loopback/monitor audio from your OS, analyses it into volume, bass, treble and BPM, and feeds those values into GLSL uniforms that drive 50 shader sketches in real time.

01

Audio capture

Loopback / monitor source via PipeWire (pw-record) or PulseAudio (parec) on Linux, WASAPI loopback (system and per-app) on Windows, ScreenCaptureKit system and per-app audio on macOS. Every backend emits the same 48 kHz stereo float32 stream, so the analysis is identical.

▸
02

Real-time analysis

Per-sample RMS volume, 80 Hz low-pass bass, 2 kHz high-pass treble and beat-detected BPM — NaN-sanitized so one bad sample can't kill the pipeline.

▸
03

Shader uniforms

Audio values are interpolated ("magic" tweening) and sent as iTime, iResolution, stream, volume, bass, treble, bpm uniforms to the sketch shader.

▸
04

Visuals render

Three.js full-screen quad runs each of the 50 GLSL fragment shaders (kaleidoscope, orbs, rotation, colour cycling) synced to the beat.

What each piece does

  • Main process (app/main.js) — owns the singleton AudioCapture, forwards 'audio:analytics-update' to the renderer over Electron IPC.
  • Audio capture (src/audio/audio-capture.js) — spawns pw-record/parec, reads PCM, computes volume/bass/treble/BPM every frame.
  • Renderer (app/renderer.js) — Three.js shader harness; wrapMainImage() splits global scope from main()/mainImage() for GLSL ES 1.0 compatibility.
  • Variants — per-sketch variant sets with Tween/TweenProgress bool interpolation; M triggers a magic tween between variants.
  • Catalog — 50 sketches / 92 variants loaded from assets/sketches.json via IPC (no brittle file:// relative fetch).
  • Now playing — track title/artist/album plus Prev/Play-Pause/Next controls via MPRIS (Linux), SMTC (Windows) or AppleScript (macOS), shown above the meters and mirrored in hidden mode (U).
Platforms

What it runs on

Cross-platform desktop builds produced by CI on every push to main, attached as release assets.

Linux

AppImage & .deb

x86_64 AppImage (~109 MB) and Debian/Ubuntu .deb (~75 MB). Captures PipeWire or PulseAudio loopback. Prefer sources named "Monitor" or "Loopback".

AppImage (x86_64) .deb (x86_64)
Windows

NSIS installer & portable

WASAPI loopback capture — system audio plus per-app process loopback (Windows 10 2004+). The capture helper ships prebuilt, so there is nothing extra to install. NSIS installer (.exe) and a portable .zip bundle.

NSIS installer (.exe) Portable (.zip)
macOS

DMG & ZIP

ScreenCaptureKit capture — system audio and per-app audio, no virtual device needed. Requires the Xcode Command Line Tools to build the helper on first run. Universal DMG and ZIP builds for Apple Silicon and Intel.

DMG (universal) ZIP (universal)
Credits

Who built every piece

Kaleidosync began as a rewrite of zachwinter's Kaleidosync; the shaders and sketch catalog come from the @wearesage/ reference. Everything else is original to this repo.

Piece Built by Notes
Kaleidosync Desktop (this repo) brgjr10 (maintainer) Full rewrite: module system, audio capture, shader wiring, variant interpolation, IPC bridge, UI gating, now-playing integration, BPM detection, desktop packaging.
Original Kaleidosync concept zachwinter Original repository that this project was rewritten from.
GLSL utilities & sketch catalog @wearesage/vue glsl-util.ts helpers (k_kale, k_orb, k_swap…) and the 50-sketch / 92-variant catalog.
Desktop framework Electron (OpenJS Foundation) Main/renderer processes, preload bridge, auto-updater-friendly build via electron-builder.
WebGL rendering three.js (mr.doob) Full-screen ShaderMaterial harness driving each GLSL sketch.
Audio backends PipeWire / PulseAudio · WASAPI · ScreenCaptureKit OS loopback/monitor capture; no Spotify API, no tokens, no DOM tapping.
Desktop integration MPRIS (Linux) · SMTC (Windows) · AppleScript (macOS) Track metadata + playback controls, gated to "playing" state; hidden-mode panel mirror.
CI / releases GitHub Actions Builds Linux/Windows/macOS on every push and auto-publishes a release tagged v2.0.0-<sha>.
